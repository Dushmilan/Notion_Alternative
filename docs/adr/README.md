# Architecture Decision Records

Each ADR documents a significant architectural decision. Use the template below.

## Template

```markdown
# [number] - [title]

**Status:** [Proposed | Accepted | Superseded]

**Date:** [YYYY-MM-DD]

## Context

What problem are we solving? What constraints or forces are at play?

## Decision

What did we choose and why? Include alternatives considered.

## Consequences

What trade-offs were accepted? What becomes easier or harder?

## Compliance

How will we enforce this decision in code review or CI?
```
